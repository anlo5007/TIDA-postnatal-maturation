# Analysis code — postnatal maturation of the TIDA–prolactin axis

MATLAB code for the electrophysiological and calcium-imaging analyses reported in:

> **Stable Network Homeostasis during Multi-Level Postnatal Maturation of the
> Mouse Tuberoinfundibular Dopamine–Prolactin Axis**
> Andrea Locarno, Andriana Mantzafou, Jimena Ferraris, Christian Broberger
> Department of Biochemistry and Biophysics, Stockholm University


- **Author:** Andrea Locarno, Stockholm University, ORCID: 0000-0003-0640-1510

## What is here

Two independent, self-contained analysis pipelines. Each is a single `.m` file
holding its configuration, its pipeline and all of its functions, so that it can
be run without any other file from this repository on the MATLAB path.

| Script | Purpose | Documentation |
|---|---|---|
| `oscillation_analysis.m` | Classifies TIDA neurons as Regular or Non-regular from the autocorrelogram of the membrane potential, and measures oscillation strength and frequency | [`docs/oscillation_analysis.md`](docs/oscillation_analysis.md) |
| `functional_connectivity_analysis.m` | Builds functional connectivity maps from pairwise cross-correlation of calcium traces | [`docs/functional_connectivity_analysis.md`](docs/functional_connectivity_analysis.md) |

Both quantify a correlation measure and test it against a null distribution
generated by block-bootstrap resampling of the same recording, which is why the
resampling function `blockbootstrp` appears, identically, in both files. The two
copies are deliberate duplication in the service of each script standing alone;
if one is edited, the other must be edited to match.


## Requirements

- MATLAB R2020a or newer
- Signal Processing Toolbox
- Statistics and Machine Learning Toolbox
- Image Processing Toolbox (only for the cell-map background of the
  connectivity map)
- `abfload.m` by Harald Hentschke, for the electrophysiology script only. It is
  third-party code with its own license and is **not redistributed here**:
  <https://www.mathworks.com/matlabcentral/fileexchange/6190>

EMF figure export requires Windows; on other platforms both scripts warn and
save PDF instead.

## Getting started

1. Clone the repository and add its folder to the MATLAB path.
2. For the electrophysiology pipeline, download `abfload.m` and put it on the
   path as well.
3. Open the script you need, edit the `CONFIGURATION` section at the top, and
   run it. Each script asks for its input folder or file in a dialog.

Before a long run, reduce the number of bootstrap iterations to about 10 to
confirm that the selections, figures and tables are as expected. Both scripts
print a runtime estimate once the first recording or pair is done.


## Reproducibility

Both scripts write a `parameters` sheet into their output workbook, recording
every configuration value, the MATLAB version and the run date, so each result
file documents how it was produced.

Both use random resampling. Setting `cfg.random_seed` to an integer makes a run
exactly repeatable; left empty, the default MATLAB stream is used and p-values
vary between runs on the order of one over the number of iterations.

Steps that depend on user clicks (the analysis window in the electrophysiology
pipeline, the time section in the imaging pipeline) are recorded in the output
tables as explicit limits, so a click-based run can afterwards be replayed
deterministically.
